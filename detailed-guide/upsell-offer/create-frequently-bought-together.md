# Häufig zusammen gekauft erstellen

Es gibt 2 Upsell-Widget-Typen:

1. **Häufig zusammen gekauft**

![](<../../.gitbook/assets/unknown (276).png>)

{% embed url="https://youtu.be/KL0GlTxJFoY?si=Ppx8wzoMH6AASzVl" %}

2. **Produkt-Add-on**

![](<../../.gitbook/assets/unknown (277).png>)

{% embed url="https://youtu.be/JVkftQsJ45o?si=_wiWOBkffz_X3StK" %}

Die Erstellung eines Häufig-zusammen-gekauft-Upsells mit BOGOS umfasst **9 Schritte**:

1. Öffnen Sie Alle Angebote > Angebot erstellen > Upsell > Häufig zusammen gekauft.
2. Richten Sie die [Upsell-Informationen](create-frequently-bought-together.md#id-1.-upsell-information) ein.
3. Definieren Sie den [Upsell-Auslöser](create-frequently-bought-together.md#id-2.-upsell-trigger), wann das Widget Ihren Kunden angezeigt wird.
4. Fügen Sie [Unterbedingungen](create-frequently-bought-together.md#id-3.-add-sub-conditions) hinzu, um zu entscheiden, wer Ihre Angebote erhalten kann (optional).
5. Definieren Sie die [Upsell-Methode](create-frequently-bought-together.md#id-4.-upsell-method), um die Upsell-Produkte auszuwählen.
6. Richten Sie einen [Rabatt](create-frequently-bought-together.md#id-5.-discount) ein (optional).
7. [Benutzerdefinierter Rabattcode](create-frequently-bought-together.md#id-6.1-custom-discount-code) & [Rabattkombination](create-frequently-bought-together.md#id-6.2-combine-with-other-discounts) (optional).
8. Klicken Sie auf Veröffentlichen.
9. [Passen Sie die Widget-Anzeige an](../customize/customize-frequently-bought-together.md).

## 1. Upsell-Informationen

* **Upsell-Name** ist der Name des Upsells, der für Kunden nicht sichtbar ist und im Bereich „Alle Angebote“ der BOGOS-App angezeigt wird, um die Verwaltung neben anderen Angeboten zu erleichtern.
* **Widget-Titel** stellt das Upsell-Angebot Kunden vor und ermutigt sie, weitere Produkte zu entdecken. Er wird prominent auf der Produktseite angezeigt.
* **Widget-Untertitel** erscheint unterhalb des Widget-Titels und ergänzt den Titel, indem er den Mehrwert des Upsells erklärt.&#x20;
* **Start- und Endzeit** für das Upsell-Angebot. Wenn das Angebot unbegrenzt verfügbar sein soll, lassen Sie das Feld „Endzeit“ leer.

## 2. Upsell-Auslöser

Definieren Sie, wie das Häufig-zusammen-gekauft-Upsell Ihren Kunden angezeigt wird. Wählen Sie aus den unten stehenden Optionen aus, um zu steuern, auf welchen Produkten oder Kollektionen das Upsell angezeigt wird.

### 2.1 Upsell immer anzeigen

Das Upsell wird auf allen Produktseiten ohne Auslöser angezeigt.

### 2.2 Ausgewählte Produkte

Das Upsell wird nur auf den von Ihnen ausgewählten spezifischen Produkten angezeigt. Dies ist nützlich, wenn Sie bestimmte Artikel ansprechen möchten, die häufig zusammen gekauft werden.

### 2.3 Alle außer ausgewählten Produkten

Das Upsell wird auf allen Produktseiten angezeigt, außer auf den spezifischen Produkten, die Sie ausschließen. Diese Option verhindert, dass das Upsell auf Produkten erscheint, die keine zusätzlichen Empfehlungen benötigen.

### 2.4 Ausgewählte Kollektionen/Typen/Anbieter

Das Upsell erscheint nur auf Produkten, die den ausgewählten Kollektionen, Produkttypen und Anbietern entsprechen.

{% hint style="info" %}
* Die Bedingungen zwischen Kollektionen, Typen und Anbietern arbeiten nach dem **UND**-Prinzip. Das bedeutet, das Produkt muss alle ausgewählten Kriterien erfüllen, um das Upsell auszulösen.
* Die Bedingungen innerhalb jeder ausgewählten Kollektion, jedes Typs oder Anbieters arbeiten nach dem **ODER**-Prinzip. Das bedeutet, das Upsell wird ausgelöst, wenn ein Produkt zu einer der ausgewählten Kollektionen, Typen oder Anbieter gehört.
{% endhint %}

**Beispiel:**

* Wenn Sie Kollektion A, Produkttyp B und Anbieter C auswählen, erscheint das Upsell nur auf Produkten, die zu Kollektion A UND Produkttyp B gehören UND von Anbieter C stammen.
* Wenn Sie jedoch mehrere Kollektionen auswählen (z. B. Kollektion A und Kollektion D), erscheint das Upsell auf Produkten aus entweder Kollektion A ODER Kollektion D, solange sie auch dem ausgewählten Produkttyp und Anbieter entsprechen.

### 2.5 Alle außer ausgewählten Kollektionen/Typen/Anbieter

Das Upsell wird auf allen Produktseiten angezeigt, außer auf denen in den ausgewählten Kollektionen, Produkttypen oder Anbietern.

## 3. Unterbedingungen hinzufügen

Unterbedingungen fügen zusätzliche Regeln hinzu, um zu entscheiden, wer Ihre Angebote sehen und erhalten kann. Dadurch können nur die angesprochenen Kunden das Angebot sehen und anwenden, während andere es überhaupt nicht sehen.

{% hint style="info" %}
* Diese Unterbedingungen sind optional. Wenn Sie keine hinzufügen, ist das Angebot für alle Kunden verfügbar.
* Sie können mehrere Unterbedingungen kombinieren. Kunden müssen alle ausgewählten Kriterien erfüllen, um qualifiziert zu sein.
{% endhint %}

<figure><img src="../../.gitbook/assets/unknown (154).png" alt="" width="503"><figcaption></figcaption></figure>

1. _Spezifische Link-Adresse_ – Wenden Sie Angebote auf Kunden an, die über einen bestimmten Link auf Ihren Shop zugreifen. Perfekt für E-Mail-Kampagnen, Social-Media-Beiträge oder Partner.
2. _Bestellhistorie_ – Sprechen Sie Kunden basierend auf ihrem Kaufverhalten an. Ideal, um Erstkäufer, Vielkäufer und mehr zu belohnen.
3. _Kundentags_ – Zeigen oder verbergen Sie Angebote basierend auf Kunden-Tags.
4. _Kundenstandort_ – Führen Sie länderspezifische Aktionen basierend auf der IP-Adresse des Kunden durch.
5. _Markets_ – Führen Sie regionsspezifische Angebote basierend auf Ihren Shopify Markets durch.

♦️ Weitere Details finden Sie in unserer Anleitung \[[Unterbedingung](../detailed-doc/how-to-add-bogos-sub-conditions-to-bundle-upsell-discount.md)].

### 4.2 Methode auswählen

Wählen Sie aus, wie Sie die Upsell-Produkte auswählen möchten. Es gibt drei Methoden: **Manuell, Automatisch und Zufällig.**

#### 4.2.1 Manuell

Wählen Sie die Produkte, die Sie als Upsell anbieten möchten, manuell aus. Sie können festlegen, welche Produkte als Upsell-Empfehlungen angezeigt werden.&#x20;

#### 4.2.2 Automatisch

Um diese Option zu nutzen, müssen Sie die [Shopify Search & Discovery App](https://apps.shopify.com/search-and-discovery) (kostenlos) in Ihrem Shop installieren. BOGOS wählt Upsell-Produkte automatisch basierend auf den mit dieser App synchronisierten Daten aus.

In den BOGOS-Einstellungen gibt es zwei Empfehlungstypen, die mit der Shopify Search & Discovery App synchronisiert werden:

* **Ergänzende Produkte:** Sie wählen empfohlene Produkte manuell innerhalb der Shopify Search & Discovery App aus.
* **Verwandte Produkte**: Shopifys KI generiert Produktempfehlungen basierend auf Shop-Daten automatisch.

{% hint style="info" %}
Für „Ergänzende Produkte“ müssen Sie Produkte manuell innerhalb der Shopify Search & Discovery App auswählen.&#x20;

Für „Verwandte Produkte“ verwendet Shopify KI, um Produktempfehlungen automatisch zu generieren.

[Klicken Sie hier, um die Hilfedokumentation dazu anzusehen.](https://help.shopify.com/en/manual/online-store/search-and-discovery/product-recommendations)
{% endhint %}

#### 4.2.3 Zufällig

Mit dieser Option zeigt BOGOS Upsell-Produkte basierend auf Ihren Einstellungen zufällig an.

* **Anzahl der Upsell-Produkte:** Legen Sie die Anzahl der empfohlenen Produkte fest.
* **Auswahlkriterien**: Wählen Sie aus, woher die zufälligen Produkte ausgewählt werden sollen:
  * Nur aus ausgewählten Typen
  * Nur aus ausgewählten Anbietern
  * Nur aus ausgewählten Kollektionen

### 4.3. Menge für aktuellen Artikel festlegen

<img src="../../.gitbook/assets/unknown (267).png" alt="" height="313.84615384615387" width="610.307210031348">

Standardmäßig **zeigt das Widget 1 Stück des Hauptartikels auf der Seite** (auch aktuelles oder Auslöserprodukt genannt).

Um dies zu ändern, aktivieren Sie „Menge für aktuellen Artikel festlegen“ und geben Sie eine neue Zahl ein.

{% hint style="info" %}
Nur für den Häufig-zusammen-gekauft-Widget-Typ verfügbar.&#x20;

Bei Produkt-Add-ons entspricht die Menge automatisch dem Hauptmengenwähler Ihres Shops.
{% endhint %}

### 4.4 Upsell-Produktmenge

Diese Einstellung steuert, **wie die Menge der Upsell-Produkte** gehandhabt wird. Bitte wählen Sie zwischen:

* **Kunden erlauben, die Menge zu ändern**: Ermöglicht Kunden, die Menge jedes Produkts anzupassen.
* **Feste Menge**: Legt eine feste Menge für Upsell-Produkte fest. Kunden können die Menge im Widget nicht ändern, können sie aber später im Warenkorb noch anpassen.
  * Wenn die Methode „**Manuell**“ verwendet wird, geben Sie die Menge direkt in den Produktauswahlfeldern ein, um eine benutzerdefinierte feste Menge festzulegen.
  * Wenn die Auswahlmethode „**Automatisch**“ oder „**Zufällig**“ verwendet wird, zeigt das Widget automatisch 1 Produkt an.

{% hint style="info" %}
Die Option „Feste Menge“ geht mit der Multiplikationsrabatt-Logik einher (erklärt im Abschnitt [5. Rabatt](create-frequently-bought-together.md#id-5.-discount)).
{% endhint %}

## 5. Rabatt

### 5.1 Rabatt aktivieren

**Wenn deaktiviert**, fügen Kunden die Upsell-Produkte zum regulären Preis hinzu.

**Wenn aktiviert**, wird ein Rabatt auf Ihre Upsell-Produkte angewendet. Die **Multiplikationslogik** gilt dabei standardmäßig ebenfalls, was bedeutet, dass sich der Rabatt mit der Anzahl der Produkte im Warenkorb skaliert.

Wenn ein Kunde zum Beispiel 1x Auslöserprodukt A + 2x Upsell-Produkt B (mit 10 % Rabatt) hinzufügt:

* Erhöhung auf 2x A + 4x B → alle 4x B werden rabattiert.
* Erhöhung auf 2x A + 3x B → 2x B werden rabattiert, 1x B wird zum vollen Preis hinzugefügt.

{% hint style="info" %}
Die Multiplikationslogik skaliert bei Häufig zusammen gekauft nach der Anzahl der einzigartigen Produkte, hängt bei Produkt-Add-ons jedoch von Ihrer Einstellung „[Wenn Auslöserprodukt entfernt wird](create-frequently-bought-together.md#id-5.3-discount-product-add-on-widget)“ ab.
{% endhint %}

### 5.2 Rabatt / Häufig-zusammen-gekauft-Widget

Um einen Rabatt mit dem Häufig-zusammen-gekauft-Widget festzulegen, folgen Sie bitte diesen Schritten:

<img src="../../.gitbook/assets/unknown (271).png" alt="" height="269" width="624">

1. Geben Sie die **Anzahl der für den Rabatt erforderlichen einzigartigen Produkte** ein. Mehrere Mengen desselben Artikels zählen nur als 1 einzigartiges Produkt.

{% hint style="info" %}
Die Multiplikationslogik basiert auf dieser Zahl.
{% endhint %}

2. **Rabatt anwenden auf:**

* **Jeden Artikel:** Der Rabatt gilt sowohl für das Auslöser- als auch für die Upsell-Produkte.
* **Jeden Artikel außer den aktuellen:** Der Rabatt gilt nur für die Upsell-Produkte. Das Auslöserprodukt wird zum vollen Preis hinzugefügt.

3. Wählen Sie **Typ**

{% hint style="info" %}
Der Rabatt wird auf den **Gesamtpreis** aller ausgewählten Produkte angewendet.
{% endhint %}

* **Prozentsatz** (z. B. 10 % Rabatt).
* **Betrag** (z. B. 10 $ Rabatt). Wenn Sie Shopify Markets eingerichtet haben, klicken Sie auf **Währung hinzufügen**, um einen benutzerdefinierten Rabattbetrag für jede Währung festzulegen (z. B. erhalten Kunden aus Singapur 10 $ Rabatt, während europäische Kunden 12 € Rabatt erhalten).

<figure><img src="../../.gitbook/assets/unknown (72).png" alt="" width="563"><figcaption></figcaption></figure>

* **Günstigster Artikel kostenlos:** Macht automatisch den günstigsten Artikel im Widget kostenlos.\\

4. **Versandrabatt hinzufügen**

<figure><img src="../../.gitbook/assets/image (27).png" alt="" width="461"><figcaption></figcaption></figure>

Es gibt zwei Arten von Versandrabatt:

* **Prozentsatz**: Ein Prozentsatz der Versandkosten wird abgezogen.
* **Betrag:** Ein fester Betrag wird von den gesamten Versandkosten abgezogen. Wenn Sie in verschiedenen Währungen verkaufen (eingerichtet in Shopify Markets), können Sie **Währung hinzufügen** und individuell festlegen, wie viel Versandrabatt in jeder Währung angeboten wird.

**Beschriftung auf dem Widget**: Dieser Text informiert Kunden darüber, ob das Angebot einen Versandrabatt beinhaltet.

### 5.3 Rabatt / Produkt-Add-on-Widget

Um einen Rabatt mit dem Produkt-Add-on-Widget festzulegen, folgen Sie bitte diesen Schritten:

<img src="../../.gitbook/assets/unknown (272).png" alt="" height="344" width="624">

1. Wählen Sie **Wenn Auslöserprodukt entfernt wird** (was mit Upsell-Produkten passiert, wenn das Auslöserprodukt aus dem Warenkorb entfernt wird):

* **Rabatt entfernen:** Der Rabatt wird von allen Upsell-Produkten entfernt. Unter der _**Multiplikationslogik**_ müssen Kunden die Menge sowohl des Auslöser- als auch der Upsell-Artikel multiplizieren.
* **Rabatt beibehalten:** Der Rabatt bleibt auf allen Upsell-Produkten bestehen. Unter der _**Multiplikationslogik**_ müssen Kunden nur die Menge der Upsell-Artikel multiplizieren.

2. Legen Sie **Begrenzte Anzahl rabattierter Artikel** fest (optional): Wenn Sie in diesem Feld 1 eingeben, während Sie 3 Upsell-Produkte anbieten, gilt der Rabatt nur für 1 Artikel. Andere werden zum vollen Preis hinzugefügt.
3. Wählen Sie **Typ**

{% hint style="info" %}
Der Rabatt wird auf den Preis jedes einzelnen Upsell-Produkts angewendet.<br>
{% endhint %}

* **Prozentsatz** (z. B. 10 % Rabatt).
* **Betrag** (z. B. 10 $ Rabatt). Wenn Sie Shopify Markets eingerichtet haben, klicken Sie auf **Währung hinzufügen**, um einen benutzerdefinierten Rabattbetrag für jede Währung festzulegen (z. B. erhalten US-Kunden 10 $ Rabatt, während kanadische Kunden 20 CA$ Rabatt erhalten).

## 6. Rabattcode

### 6.1 Benutzerdefinierter Rabattcode

Standardmäßig **generiert BOGOS automatisch einen zufälligen Rabattcode** (z. B. BOGOS-XSJSC) für den Rabatt. Dieser Code wird automatisch im Warenkorb des Kunden angewendet.

Sie können diesen automatisch generierten Code jedoch durch einen benutzerdefinierten Namen ersetzen, der zu Ihrer Strategie passt (z. B. SUMMER20). Füllen Sie dazu das Feld **Benutzerdefinierter Rabattcode** aus.

<figure><img src="../../.gitbook/assets/unknown (63).png" alt=""><figcaption></figcaption></figure>

{% hint style="info" %}
Der Name des Rabattcodes muss unter 256 Zeichen liegen und über alle mit Shopify-Rabatten erstellten Rabatte hinweg eindeutig sein.
{% endhint %}

### 6.2 Mit anderen Rabatten kombinieren

Standardmäßig funktioniert BOGOS Häufig zusammen gekauft mit jedem anderen Rabatt. Um die Kombination zu verhindern, können Sie die gewünschte Option **deaktivieren**:

<figure><img src="../../.gitbook/assets/image (325).png" alt=""><figcaption></figcaption></figure>

* **Bestellrabatt**: Gibt an, ob der Upsell-Rabatt mit Rabatten auf Bestellebene kombiniert werden kann, wie z. B. Aktionscodes oder automatischen Rabatten.
* **Versandrabatt**: Gibt an, ob der Upsell-Rabatt mit Versandrabatten kombiniert werden kann, wie z. B. kostenlosem oder reduziertem Versand.

{% hint style="info" %}
Die Kombinationseinstellungen richten sich nach den Rabattregeln von Shopify. Stellen Sie sicher, dass die Rabatte, die Sie kombinieren möchten, ebenfalls so konfiguriert sind, dass eine Kombination erlaubt ist.
{% endhint %}

## FAQs

<details>

<summary><strong>Ist es möglich, „Kostenlosen Versand beim Kauf von Upsell-Produkten erhalten“ einzurichten</strong></summary>

Ja, das können Sie problemlos einrichten. Wie im Screenshot dargestellt, müssen Sie den **Produktrabatt auf 0 %** und den **Versandrabatt auf 100 %** setzen. Dies bietet effektiv kostenlosen Versand beim Kauf der Upsell-Artikel, ohne die Artikel selbst zu rabattieren.

![](<../../.gitbook/assets/unknown (214).png>)

</details>

<details>

<summary><strong>Ist es möglich, einen Rabatt nur für Upsell-Produkte anzuwenden</strong></summary>

Ja. In den Rabatteinstellungen können Sie wählen, den Rabatt auf **„Jeden Artikel außer den aktuellen“** (das Hauptprodukt) anzuwenden.

![](<../../.gitbook/assets/unknown (215).png>)

</details>

<details>

<summary><strong>Wie kann ich die Position des Häufig-zusammen-gekauft-Widgets ändern?</strong></summary>

Um die Position des Häufig-zusammen-gekauft-Widgets zu ändern, folgen Sie bitte diesen Schritten:&#x20;

* Schritt 1: Gehen Sie zu Shopify-Admin > Onlineshop > Themes > Theme bearbeiten > Produktseite

![](<../../.gitbook/assets/unknown (216).png>)

* Schritt 2: Klicken Sie bei den Produktinformationen an der gewünschten Position auf „Häufig zusammen gekauft“-Block hinzufügen

![](<../../.gitbook/assets/unknown (217).png>)

</details>
